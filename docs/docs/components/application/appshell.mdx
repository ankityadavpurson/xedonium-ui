---
title: "AppShell"
sidebar_position: 3
---

Header on top, `sidebar` on the left, scrolling main area. Below the `md` breakpoint the sidebar moves into a drawer
behind a menu button. `sidebar` can be a function `(close) => node` to close the drawer on selection. The shell fills
the viewport height; size it with `className` when embedding.

```jsx live
function Demo() {
	const [active, setActive] = useState('home')
	return (
		<AppShell
			className="!h-96 border border-app-border"
			header={<strong>Acme</strong>}
			sidebar={close => (
				<Sidebar
					activeKey={active}
					onSelect={key => {
						setActive(key)
						close()
					}}
					items={[
						{ key: 'home', label: 'Home', icon: <HomeIcon /> },
						{ key: 'settings', label: 'Settings', icon: <SettingsIcon /> },
					]}
				/>
			)}
		>
			<p>Showing: {active}</p>
		</AppShell>
	)
}
```
