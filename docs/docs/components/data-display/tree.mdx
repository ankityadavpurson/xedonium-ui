`nodes: [{ key, label, children? }]`. Keyboard: Up / Down move, Right expands or enters, Left collapses or goes to
the parent, Enter selects. Pass `defaultExpanded` (keys), or control it with `expanded` + `onExpandedChange`.

```jsx live
function Demo() {
	const [selected, setSelected] = useState('button')
	return (
		<Tree
			label="Files"
			selected={selected}
			onSelect={setSelected}
			defaultExpanded={['src']}
			nodes={[
				{
					key: 'src',
					label: 'src',
					children: [
						{ key: 'button', label: 'Button.jsx' },
						{ key: 'hooks', label: 'hooks', children: [{ key: 'esc', label: 'useEscapeKey.js' }] },
					],
				},
				{ key: 'readme', label: 'README.md' },
			]}
		/>
	)
}
```
