---
title: "DateRangePicker"
sidebar_position: 3
---

Click the start, then the end (either order). The value is `{ start, end }`.

```jsx live
function Demo() {
	const [range, setRange] = useState({ start: null, end: null })
	return (
		<div className="w-72">
			<DateRangePicker label="Stay" value={range} onChange={setRange} />
		</div>
	)
}
```
