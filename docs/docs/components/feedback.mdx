## Alert

`tone`: `info`, `success`, `warning`, `danger`. `onClose` makes it dismissible.

```jsx live
<Stack gap={3}>
	<Alert title="Heads up">Something you should know.</Alert>
	<Alert tone="success" title="Saved">
		Your changes were saved.
	</Alert>
	<Alert tone="warning" title="Careful">
		This cannot be undone.
	</Alert>
	<Alert tone="danger" title="Failed" onClose={() => {}}>
		Could not reach the server.
	</Alert>
</Stack>
```

## Progress

Omit `value` for an indeterminate bar.

```jsx live
<Stack gap={4}>
	<Progress label="Uploading" value={62} showValue />
	<Progress label="Working" />
</Stack>
```

## Skeleton

```jsx live
<Flex gap={4} align="start">
	<Skeleton circle className="h-10 w-10" />
	<div className="flex-1">
		<Skeleton lines={3} />
	</div>
</Flex>
```

## Toast / Snackbar

Transient messages are covered by [`Toast`](./overlays#toast) with `useTimedToast`.
