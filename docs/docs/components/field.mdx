---
title: Field
---

Labelled input. Props: `label`, `value`, `onChange` (receives the value string), `placeholder`, `error`, `type`,
`autoComplete`, `required`.

```jsx live
function Demo() {
	const [name, setName] = useState('')
	return (
		<div className="w-72">
			<Field
				label="Name"
				value={name}
				onChange={setName}
				placeholder="Type here"
				error={name === 'x' ? 'Too short' : ''}
			/>
		</div>
	)
}
```
