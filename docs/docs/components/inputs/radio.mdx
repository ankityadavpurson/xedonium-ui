sidebar_position: 6
---

`Radio` is the single control; `RadioGroup` manages a set and calls `onChange` with the chosen value.

```jsx live
function Demo() {
	const [size, setSize] = useState('m')
	return (
		<RadioGroup
			label="Size"
			value={size}
			onChange={setSize}
			direction="row"
			options={[
				{ value: 's', label: 'Small' },
				{ value: 'm', label: 'Medium' },
				{ value: 'l', label: 'Large' },
			]}
		/>
	)
}
```
