---
title: "PageLayout and PageHeader"
sidebar_position: 5
---

`PageLayout` accepts `maxWidth`, `centerContent`, `themeToggle`, `outerClassName` and `innerClassName`. `PageHeader`
takes `title`, `subtitle` and action children.

```jsx live
<PageHeader title="Playground" subtitle="Every component, light and dark">
	<Button variant="secondary">Action</Button>
</PageHeader>
```
