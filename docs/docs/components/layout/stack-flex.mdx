title: "Stack & Flex"
sidebar_position: 2
---

`Stack` is a vertical `Flex`; use `direction="row"` for horizontal. `gap` is 0-4, 6 or 8. `Flex` also takes `align`,
`justify`, `wrap` and `inline`.

```jsx live
<Stack gap={3}>
	<Flex align="center" justify="between">
		<span>Left</span>
		<Button variant="secondary">Right</Button>
	</Flex>
	<Stack direction="row" gap={2}>
		<Button>One</Button>
		<Button>Two</Button>
	</Stack>
</Stack>
```
