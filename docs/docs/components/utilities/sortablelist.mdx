---
title: "SortableList (drag and drop)"
sidebar_position: 3
---

Reorder by dragging, or focus a row's handle and press Up / Down. Items need a unique `key`; `onChange` receives the
new order.

```jsx live
function Demo() {
	const [items, setItems] = useState([
		{ key: 'a', label: 'Design' },
		{ key: 'b', label: 'Build' },
		{ key: 'c', label: 'Ship' },
	])
	return <SortableList items={items} onChange={setItems} renderItem={item => item.label} />
}
```
