- `useTimedToast()` returns `{ toast, showToast(msg, type?) }`.
- `useEscapeKey`, `useDialogFocus` (focus trap for dialogs), `useLeaveWarning` (unsaved-changes prompt).
- `useDocumentTitle(title, suffix)`.
- `ThemeProvider` (`storageKey`, `favicon`, `faviconTitle`), `useTheme`, `useAppTheme`, `buildFaviconHref`.
