title: Introduction
---

Xedonium is a small set of React components styled with Tailwind. Corners are square, colors come from semantic
`app-*` tokens, and light/dark follows `<html data-theme>`.

Every example in these docs is live: edit the code and the preview updates.

```jsx live
<div className="flex flex-wrap gap-3">
	<Button>Default</Button>
	<Button variant="secondary">Secondary</Button>
	<Button variant="danger">Danger</Button>
	<Button variant="warning">Warning</Button>
</div>
```

Use the color toggle in the navbar to see the components in both themes.
